🦊 Cara Pakai di Firefox Saja

Browser Chrome, Edge, Game, dan Windows tetap menggunakan koneksi biasa (IP asli). Hanya Firefox yang dialihkan lewat VPN:

  1. Buka Firefox → Settings (Pengaturan).
  2. Ketik "proxy" di kolom cari → Klik Settings...
  3. Pilih Manual proxy configuration:
    • HTTP Proxy: 127.0.0.1 | Port: 10808
    • Atau SOCKS Host: 127.0.0.1 | Port: 10809 (Pilih SOCKS v5)
  4. Klik OK. Selesai!
